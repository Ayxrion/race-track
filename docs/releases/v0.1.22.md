# Race Track Firmware v0.1.22

Racing decisions now create overtaking opportunities without giving attacking cars extra engine power. GitHub OTA and the saved spectator relay configuration remain enabled.

- Removed push-to-pass speed/acceleration, position-based catch-up and leader slowdown.
- Replaced lingering tow assistance with a modest physical wake and progressive loss of existing momentum after pulling out.
- Added attack preparation, sustained clearance, consistent cleanup and mutual opponent cooldowns. A genuine small speed advantage has time to complete a move.
- Added stable driver traits and separate random streams, with a shared snapshot of traffic for each simulation step.
- Qualifying now estimates a circuit-specific lap using class, driver, braking, acceleration and conditions. Start reactions account for skill.
- Added soft/medium/hard dry-tyre strategies. Grip and braking plans account for tyre wear; pit decisions respond to traffic, remaining distance, weather and safety cars.
- Kept the existing championship points. Retired or unfinished cars no longer earn wins, podiums or best-finish records. Slow classes get sufficient time to finish after the flag, and an all-retired race reaches results.
- Race logs count sustained overtakes rather than repeated overlap swaps, and include qualifying/driver/tyre details.

Existing championship, career and telemetry NVS formats are unchanged. Historical records are retained; previously miscounted podiums cannot be reconstructed automatically.

The automated host suite runs the actual geometry, physics, race control and championship code with hardware boundaries replaced. It checks repeat-attack acceleration, position independence, update-order invariance in controlled traffic, qualifying, tyre tradeoffs, retirement scoring, persistence, sustained pass counting and complete races. The release workflow runs these checks before publishing `firmware.bin`.

Install normally by restarting the configured ESP32 with Wi-Fi available. Do not erase NVS or reflash a telemetry-disabled build. This release does not require changing the webapp or relay protocol.
