# Race Track Firmware v0.1.23

Fixes intermittent `JSON parse error (IncompleteInput)` during the GitHub OTA check.

The Arduino-ESP32 3.3.0 network reader can stop when a TLS record is temporarily unavailable. The OTA parser now uses a buffered reader that waits for subsequent packets, with bounded idle/overall timeouts and response size. Incomplete metadata is retried on a fresh connection up to three attempts. Stream timeout values are expressed in milliseconds, and unexpected transfer/content encodings are rejected before parsing.

Release summaries are kept short for older firmware; detailed notes remain in the tagged repository. The v0.1.22 summary was shortened without changing its binary or version tag.

Tests reproduce the old failure on fragmented JSON with ArduinoJson 6.21.6, then verify the production reader succeeds. Additional cases cover truncation, idle timeout, overall timeout, response size and clock rollover.

Includes all v0.1.22 AI changes. GitHub OTA, spectator relay settings, championship and career persistence are retained.
